
Main module to run the algorithms.

flags:

optimal_stopping/run/run_algo.py:
  --[no]DEBUG: Turn on debug mode
    (default: 'false')
  --algos: Name of the algos to run.
    (a comma separated list)
  --[no]compute_greeks: Whether to compute greeks (not available for all
    settings)
    (default: 'false')
  --[no]compute_upper_bound: Whether to additionally compute upper bound for
    price
    (default: 'false')
  --eps: the epsilon for the finite difference method or regression
    (default: '1e-09')
    (a number)
  --[no]fd_compute_gamma_via_PDE: Whether to use the PDE to compute gamma
    (default: 'true')
  --[no]fd_freeze_exe_boundary: Whether to use same exercise boundary
    (default: 'true')
  --[no]generate_pdf: Whether to generate latex tables
    (default: 'false')
  --greeks_method: one of: central, forward, backward, regression
    (default: 'central')
  --nb_jobs: Number of CPUs to use parallelly
    (default: '47')
    (an integer)
  --nb_stocks: List of number of Stocks
    (a comma separated list)
  --path_gen_seed: Seed for path generation
    (an integer)
  --poly_deg: the degree for the polynomial regression
    (default: '2')
    (an integer)
  --[no]print_errors: Set to True to print errors if any.
    (default: 'false')
  --reg_eps: the epsilon for the finite difference method or regression
    (default: '5.0')
    (a number)
  --train_eval_split: divisor for the train/eval split
    (default: '2')
    (an integer)

    (default: 'false')
