## 1. Постановка задачи: американский опцион и оптимальная остановка

### 1.1. Непрерывное время (понятийно)

Пусть на отрезке $$0,T$$ задана адаптированная к фильтрации цены базовых активов случайная траектория $X_t$ (в одномерном случае часто $X_t = S_t$). **Американский** дериватив с выплатой $g(t, X_t)$ даёт право **выбрать момент остановки** $\tau \le T$ и получить $g(\tau, X_\tau)$. Цена под риск-нейтральной мерой (схематично):

$$
V_0 = \sup_{\tau \in \mathcal{T}_{0,T}} \mathbb{E}\left$ e^{-r\tau}\, g(\tau, X_\tau) \right$,
$$

где $\mathcal{T}_{0,T}$ — класс допустимых моментов остановки, $r$ — безрисковая ставка. Это классическая **задача оптимальной остановки**.

### 1.2. Бермуданское приближение (как в численных экспериментах)

На практике вводят дискретную сетку дат исполнения $0 = t_0 < t_1 < \cdots < t_N = T$. Обозначим $X_k = X_{t_k}$, $g_k(X_k) = g(t_k, X_k)$. Задача сводится к **конечномерной** оптимальной остановке по марковской цепи $(X_k)$.

**Ценность** (Snell envelope в дискретном времени) задаётся **обратной индукцией** с конца:

- На последней дате $N$:
  $$
  V_N(X_N) = g_N(X_N).
  $$
- Для $k = N-1, N-2, \ldots, 0$:
  $$
  V_k(X_k) = \max\left\{\, g_k(X_k),\; \mathbb{E}\left$ e^{-r\Delta t}\, V_{k+1}(X_{k+1}) \,\big|\, X_k \right$ \,\right\},
  $$
  где $\Delta t = t_{k+1} - t_k$ (при равномерной сетке можно считать $\Delta t = T/N$ в годах).

Интерпретация:

- $g_k(X_k)$ — **немедленное исполнение** (intrinsic value);
- $\mathbb{E}$\cdots | X_k$$ — **continuation value** (ожидаемая дисконтированная ценность продолжения), если **ещё не** исполнили опцион в момент $k$.

Оптимальная стратегия: в момент $k$ **исполнять**, если
$$
g_k(X_k) \ge C_k(X_k) := \mathbb{E}\left$ e^{-r\Delta t}\, V_{k+1}(X_{k+1}) \,\big|\, X_k \right$,
$$
и **держать** в противном случае. На практике $C_k(\cdot)$ **неизвестно в явном виде** и оценивается по **Монте-Карло**: по множеству независимых траекторий $\{X^{(i)}\}_{i=1}^M$.

### 1.3. Монте-Карло по траекториям

Имеем $M$ траекторий, на каждой — значения $X_k^{(i)}$. После шага индукции для каждой траектории хранится **текущая оценка** будущей ценности (в библиотечной схеме это одно скалярное значение на пути с конца; см. переменная `values` в коде). На шаге $k$ для всех путей известны:

- вход в регрессию: вектор состояния $x^{(i)} = X_k^{(i)} \in \mathbb{R}^d$ (часто $d=1$ для одного актива);
- **целевая переменная** для обучения аппроксимации продолжения: дисконтированная «цена держания» с вчерашнего шага индукции (в коде это `y_next`).

Точное соответствие с реализацией: на дате `date` используются пути `stock_paths$:, :, date$`, а отклик строится из накопленного `values` с умножением на дискретный дисконт-фактор `disc_factor` за один шаг.

Обозначим одношаговый дисконт-фактор
$$
\beta = e^{-r\Delta t}.
$$



## 2. Общая схема обратной индукции в методе «LSM-подобных» алгоритмов

Фиксируем $k \in \{1,2,\ldots,N-1\}$ (в коде индексы идут от предпоследней даты к первой). **Шаги одной итерации**:

1. Вычислить **текущую немедленную выплату** на всех путях: $Z^{(i)} = g_k(x^{(i)})$.
2. Взять **ответ регрессии** с предыдущего временного слоя с учётом дисконта: целевая переменная $Y^{(i)}$ (в коде — `y_next`) соответствует дисконтированной уточнённой ценности «если не исполнили сейчас».
3. Выбрать подмножество траекторий для обучения (часто только **в деньгах**, ITM: $Z^{(i)} > 0$) — это снижает дисперсию регрессии (классический приём Longstaff–Schwartz).
4. **Обучить аппроксиматор** $\widehat{C}_k(x)$ функции продолжения $C_k(x)$, минимизируя ошибку приближения к $Y^{(i)}$ на выбранных путях:
   $$
   \widehat{C}_k \in \arg\min_{f \in \mathcal{F}} \frac{1}{|\mathcal{I}_k|} \sum_{i \in \mathcal{I}_k} \bigl( Y^{(i)} - f(x^{(i)}) \bigr)^2
   $$
   (для LSM и RLSM это линейная регрессия; для NLSM — стохастический градиент по нейросети).
5. Для **всех** путей вычислить $\widehat{C}_k(x^{(i)})$ и обновить правило остановки:
   - если $Z^{(i)} > \widehat{C}_k(x^{(i)})$ (в варианте `train_itm_only` в коде добавляются пороги на мелкие выплаты), положить «исполняем сейчас» и зафиксировать текущую ценность на пути равной $Z^{(i)}$;
   - иначе переносим оценку на шаг назад с дисконтом (перемножение на $\beta$ в цепочке индукции).
6. Сохранить **снимок** модели на дату $k$ (коэффициенты LSM / веса NLSM / веса RLSM и состояние резервуара), чтобы потом можно было вычислять $V(x,k)$ и дельты.

**Различие LSM / NLSM / RLSM** — только в выборе класса функций $\mathcal{F}$ и способе подбора параметров.



## 3. LSM (Least Squares Monte Carlo, Longstaff–Schwartz, 2001)

### 3.1. Идея

Continuation value аппроксимируется **линейной комбинацией заранее заданных базисных функций** от состояния $x \in \mathbb{R}^d$:

$$
\widehat{C}_k(x) = \sum_{j=1}^{J} \theta_{k,j}\, \phi_j(x) = \theta_k^\top \phi(x).
$$

Здесь $\phi(x) = (\phi_1(x), \ldots, \phi_J(x))^\top$ — вектор признаков. В библиотеке `optimal_stopping` они задаются объектом `BasisFunctions(nb_stocks)` (полиномы низкой степени, перекрёстные члены при $d>1$).

### 3.2. Оценка коэффициентов

На множестве индексов ITM $\mathcal{I}_k$ решается задача **МНК**:

$$
\theta_k = \arg\min_{\theta} \sum_{i \in \mathcal{I}_k} \bigl( Y^{(i)} - \theta^\top \phi(x^{(i)}) \bigr)^2.
$$

В матричном виде: столбцы матрицы признаков — $\phi(x^{(i)})$, вектор откликов — $Y^{(i)}$. В коде (`backward_snapshots.py`):

- собирается `reg_mat` размера $M \times J$;
- решается `np.linalg.lstsq(reg_mat$in_m$, y_next$in_m$)`.

### 3.3. Пошаговый алгоритм LSM (словами)

**Инициализация.** На $k=N$ для каждого пути положить «ценность опциона с конца» равной финальной выплате $g_N(x_N^{(i)})$.

**Цикл по $k = N-1, N-2, \ldots, 1$:**

1. $Z^{(i)} := g_k(x_k^{(i)})$.
2. $Y^{(i)} := \beta \cdot (\text{текущая сохранённая ценность на пути после шага } k{+}1)$.
3. Выбрать подмножество путей с $Z^{(i)} > 0$ среди первых `split` траекторий (обучение).
4. Подобрать $\theta_k$ по МНК: аппроксимировать $Y^{(i)}$ через $\theta_k^\top \phi(x_k^{(i)})$.
5. Для всех путей вычислить $\widehat{C}_k^{(i)} = \theta_k^\top \phi(x_k^{(i)})$.
6. Если $Z^{(i)} > \widehat{C}_k^{(i)}$ (и доп. условия в коде по ITM), считать, что опцион исполняют в $k$; иначе обновить ценность на пути через дисконт (как в коде `values = np.where(...)`).

**Оценка $V_0$.** После цикла из **валидационной** половины путей (`split`…конец) усредняют финальные дисконтированные ценности и берут максимум с немедленной выплатой в $t_0$ (см. `est_price` в коде).

### 3.4. Плюсы и минусы для диплома

- **Плюсы:** быстро; при малой размерности $d$ и удачном базисе даёт очень хорошую точность (классика).
- **Минусы:** **проклятие размерности** — число базисных функций растёт быстро с $d$; полиномы становятся нестабильными; производные по цене (дельта) через полиномиальную поверхность могут быть шумными.



## 4. NLSM (Neural Least Squares Monte Carlo)

### 4.1. Идея

Вместо фиксированного полиномиального базиса берут параметрическое семейство

$$
\widehat{C}_k(x) = f_{\mathrm{NN}}(x;\, \Theta_k),
$$

где $f_{\mathrm{NN}}$ — **полносвязная нейросеть** (в проекте — класс `NetworkNLSM`: входная размерность $d$, скрытый слой размера `hidden_size`, нелинейность, выходной скаляр).

### 4.2. Обучение

На том же ITM-подмножестве решается задача минимизации **MSE** методом **Adam** (стохастические мини-батчи):

$$
\Theta_k = \arg\min_{\Theta} \frac{1}{|\mathcal{I}_k|} \sum_{i \in \mathcal{I}_k} \bigl( Y^{(i)} - f_{\mathrm{NN}}(x^{(i)}; \Theta) \bigr)^2.
$$

Число эпох `nb_epochs_nlsm` задаёт качество подгонки и время.

### 4.3. Пошаговый алгоритм NLSM

Тот же внешний цикл обратной индукции, что в разделе 2, но на шаге $k$:

1. Если ITM-путей слишком мало (в коде `< 5`), используется fallback.
2. Иначе обучается сеть, в память сохраняется `state_dict` (веса всех слоёв).
3. Для всех ITM-путей континуация — значение сети на $x_k^{(i)}$.

### 4.4. Связь со статьёй и практическое значение

Статья Herrera et al. подчёркивает необходимость **нелинейных** аппроксиматоров в высоких размерностях; NLSM — «полный» нейросетевой базовый метод. Для диплома важно: **autograd** для $\nabla_x f_{\mathrm{NN}}$ после обучения. **Минусы:** дороже в обучении; чувствительность к данным и гиперпараметрам.



## 5. RLSM (Randomized Least Squares Monte Carlo) по статье Herrera et al. (2024)

### 5.1. Идея «randomized neural network»

Строят **случайное нелинейное признаковое пространство** (reservoir / random features):

1. Матрица весов **скрытого** слоя $W \in \mathbb{R}^{m \times d}$ и смещения $b \in \mathbb{R}^m$ фиксируются (сэмплируются из распределения), **не** обучаются градиентным спуском.
2. Вектор скрытых нейронов:
   $$
   h(x) = \sigma(Wx + b) \in \mathbb{R}^m,
   $$
   где $\sigma$ — покомпонентная нелинейность (ReLU / LeakyReLU и т.д.).
3. **Обучают только выходной слой** (линейную комбинацию):

   $$
   \widehat{C}_k(x) = a^\top h(x) + a_0
   $$
   (в коде $a_0$ реализуется добавлением столбца единиц к признакам).

### 5.2. Связь с random features

Тот же принцип, что в классических random features: фиксированные $(w_\ell, b_\ell)$, оптимизируются коэффициенты $a_\ell$. Статья анализирует свойства и показывает выгоду RLSM над полиномиальным LSM при большом $d$ (напр. Max-Call на многих активах).

### 5.3. Реализация в проекте

В `backward_snapshots.py`: `ReservoirLeastSquares2`, признаки $\tilde{\Phi} = $h(X)\;\; \mathbf{1}$$, МНК `lstsq` на ITM, значение $\widehat{C}_k^{(i)} = \tilde{\phi}(x_k^{(i)})^\top \theta$ для всех путей.

### 5.4. Дельта (интуиция)

$\widehat{C}(x) = \theta^\top \tilde{h}(x)$, $\tilde{h}$ — композиция аффинного отображения и $\sigma$; производная по $x$ через цепное правило, без набора конечных разностей по каждой координате (важно при большом $d$).

## 9. Архитектура нейронных сетей

### 1. Одинаковая архитектура для честного сравнения

Во всех алгоритмах используется **одинаковая архитектура нейросети**:

* одинаковое число скрытых слоёв
* одинаковое число нейронов в слоях

### Зачем

Если архитектуры разные:

* одна сеть может быть **мощнее → лучше точность**
* но медленнее
* другая — наоборот

Тогда невозможно понять:
**алгоритм лучше или просто сеть сильнее**

### Вывод

Это контроль переменных:

> сравниваются именно методы (RLSM, RFQI, DOS…), а не архитектуры

### 2. Один скрытый слой

Оказалось:

* 1 скрытый слой → уже хорошая точность
* добавление слоёв → **не улучшает результат**


Сеть:
$
y = W_2 \cdot \sigma(W_1 x + b_1) + b_2
$

### Почему так происходит

В задачах оптимальной остановки:

* функция continuation value обычно **гладкая**
* не требует глубокой иерархии признаков

👉 Это не CV и не NLP — тут нет сложной структуры

Используем:

> shallow network = проще + быстрее + достаточно точно


### 3. 20 нейронов в скрытом слое

### Архитектура:

$
x \rightarrow \text{Hidden (20 neurons)} \rightarrow y
$

### Почему 20?

* компромисс:

  * слишком мало → недообучение
  * слишком много → переобучение + шум

### Особый случай: RFQI

$
\text{neurons} = \min(20, \text{число акций})
$

### Почему?

Если:

* признаков мало
* а нейронов много

→ матрицы становятся плохо обусловленными
→ нестабильность обучения

###  Leaky ReLU

$
f(x) = \begin{cases}
x, & x > 0 \
\alpha x, & x \le 0
\end{cases}
$

✔ не "убивает" градиенты
✔ стабильнее ReLU



###  tanh

$
f(x) = \tanh(x)
$

✔ значения в $-1, 1$
✔ хорошо для рекуррентных сетей


###  sigmoid

$
f(x) = \frac{1}{1 + e^{-x}}
$

✔ интерпретация как вероятность
👉 идеально для:

* решений "останавливаться / нет"

* регрессия → ReLU / Leaky ReLU
* вероятность → sigmoid
* рекуррентность → tanh

### 5. Случайные параметры (A, b) в RLSM и RFQI

### Что это значит

В этих методах:

* часть сети **не обучается**
* веса задаются случайно

$
A \sim \mathcal{N}(0,1), \quad b \sim \mathcal{N}(0,1)
$

### Это похоже на:

👉 Random Features / Extreme Learning Machine


### Зачем?

* обучение становится:

  * быстрее
  * проще (линейная регрессия сверху)


### Почему нормальное распределение?

$
\mathcal{N}(0,1)
$

* симметрия
* хорошее покрытие пространства
* стандартный baseline


Гиперпараметры почти не влияли → оставили стандарт

### 6. RRLSM (рекуррентная случайная сеть)

### Структура:

$
h_t = \tanh(A_h h_{t-1} + A_x x_t)
$

### Параметры:

* для входа:
  $
  A_x \sim \sigma = 0.0001
  $

* для состояния:
  $
  A_h \sim \sigma = 0.3
  $



### Почему такие значения?

* маленький (A_x):

  * вход не "взрывает" систему

* умеренный (A_h):

  * память сохраняется
  * нет взрыва градиентов


Это тонкая настройка динамики:

> баланс между памятью и стабильностью



### 7. Использовать payoff как вход или нет?

### Вход сети может быть:

$
x = (S_t, \text{payoff})
$

или

$
x = S_t
$



### Результаты:

| Тип метода                      | Лучше с payoff? |
| - |  |
| Backward (LSM, RLSM, DOS, NLSM) | ✅ Да            |
| RL (FQI, RFQI)                  | ❌ Нет           |



### Почему?

### Backward induction

* напрямую сравнивает:
  $
  \text{payoff} \ vs \ continuation
  $

👉 логично дать payoff в вход



### Reinforcement Learning

* учит Q-функцию:
  $
  Q(s,a)
  $

👉 payoff уже "вшит" в reward
→ дополнительный вход может мешать



### Вывод

Разные парадигмы → разные оптимальные входы

# 📌 1. NLSM (Neural Least Squares Monte Carlo)

## 🧠 Архитектура

!$Image$(https://miro.medium.com/v2/resize%3Afit%3A1400/1%2Abz59rluxfbLe55oQ3bIeEw.png)

!$Image$(https://mukulrathi.com/static/648e5207805f95bf09c330a43d89d295/f207c/neural-net.png)

!$Image$(https://www.researchgate.net/publication/349914543/figure/fig2/AS%3A999290017165331%401615260714713/Example-neural-network-with-two-hidden-layers-for-value-function-approximation-of-the.png)

### Структура сети

Обычная feedforward-сеть:

$
S_t \longrightarrow $ \text{Hidden Layer (20)} $ \longrightarrow $ \hat{C}(S_t)
$

где:

* $(S_t)$ — состояние (например, цены активов)
* $(\hat{C}(S_t))$ — continuation value



## 📐 Формула сети

$
\hat{C}(S_t) = W_2 \cdot \sigma(W_1 S_t + b_1) + b_2
$

где:

* $(W_1 \in \mathbb{R}^{20 \times d})$
* $(W_2 \in \mathbb{R}^{1 \times 20})$
* $(\sigma)$ — активация (Leaky ReLU)



## 📉 Обучение

На каждом шаге backward induction:

$
\min_{W_1, W_2} ; \mathbb{E} [
\left( Y_t - \hat{C}(S_t) \right)^2
]
$

где:

* (Y_t) — target (дисконтированная будущая выплата)



## 📌 Интерпретация

👉 NLSM = LSM, но:

* вместо базисных функций (полиномов)
* используется нейросеть



# 📌 2. RLSM (Randomized Least Squares Monte Carlo)

## 🧠 Архитектура

!$Image$(https://www.researchgate.net/publication/327395334/figure/fig2/AS%3A672961652600832%401537457969007/System-Architecture-of-Random-Neural-Network-based-IDS.ppm)

!$Image$(https://media.springernature.com/lw685/springer-static/image/art%3A10.1007%2Fs11042-021-11007-7/MediaObjects/11042_2021_11007_Fig4_HTML.png)

!$Image$(https://www.researchgate.net/publication/329948785/figure/fig2/AS%3A708504310538242%401545931999751/Neural-network-with-fixed-weight-random-projection-layer.png)

### Структура

$
S_t $ \longrightarrow $ \text{Random Hidden Layer} $ \longrightarrow $ \text{Linear Output}
$

⚠️ Важно:

* первый слой **не обучается**



## 📐 Формула сети

### Шаг 1: случайные признаки

$
\phi(S_t) = \sigma(A S_t + b)
$

где:

* $(A \sim \mathcal{N}(0,1))$
* $(b \sim \mathcal{N}(0,1))$



### Шаг 2: линейная регрессия

$
\hat{C}(S_t) = \beta^\top \phi(S_t)
$



## 📉 Обучение

Оптимизируем только (\beta):

$
\min_{\beta} ; \mathbb{E} \left[
\left( Y_t - \beta^\top \phi(S_t) \right)^2
\right]
$

👉 Это **обычная линейная регрессия**
############


## 📌 Интерпретация

RLSM ≈
👉 нейросеть без обучения скрытого слоя
👉 random features + regression



# ⚖️ Главное различие

| Характеристика | NLSM       | RLSM                  |
| -- | - |  |
| Скрытый слой   | обучается  | случайный             |
| Параметры      | (W_1, W_2) | только (\beta)        |
| Тип модели     | нелинейная | линейная по признакам |
| Скорость       | медленнее  | быстрее               |
| Стабильность   | ниже       | выше                  |



# 📊 Интуитивное сравнение

### NLSM:

> "Я сам найду лучшие признаки"

### RLSM:

> "Я сгенерирую много случайных признаков и выберу линейную комбинацию"



# 🔁 Связь с задачей оптимальной остановки

В обоих случаях мы аппроксимируем:

$
C(S_t) = \mathbb{E}$V_{t+1} \mid S_t$
$

и затем:

$
V_t = \max(\text{payoff}, C(S_t))
$



### Ключевая идея

* NLSM → **гибкость**
* RLSM → **простота и скорость**
