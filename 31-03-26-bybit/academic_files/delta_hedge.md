| Аспект           | LSM                                   | RLSM/NLSM                       |
| ---------------- | ------------------------------------- | ------------------------------- |
| Скорость Δ       | Пересчет регрессии O(nb_paths)        | 1 forward pass O(1)             |
| Точность Δ       | Numerical ε-bump нестабилен при σ=70% | Autograd ∂r/∂S точный           |
| Многомерность    | d>3 → экспоненциальный рост basis     | Reservoir scales to d=10+       |
| Нестационарность | Полиномы не ловят regime shifts       | NN аппроксимирует любые функции |
| Online           | Полное переобучение ежедневно         | Readout update за секунды       |


Дельта вычисляется **дважды** в разных местах: **медленно при обучении** (на 1070 путях) и **быстро при торговле** (на 1 реальной цене). Полиномы кажутся быстрыми, но проблема в **повторном регрессионном фите** для каждой точки.

## Когда и где вычисляется дельта

### Фаза 1: Обучение модели (медленно, 1 раз в день)
```
Для каждого временного шага i=29 downto 0:
1. Берем 1070 нормированных путей S*[j,i] на шаге i
2. Регрессия: X[j] = [L₀(S*[j,i]), L₁, ..., L₅] → V_cont*[j]
3. Сохраняем веса w_i = [w₀, w₁, ..., w₅] для шага i
```

**LSM**: полный OLS фит на всех 1070 точках → **O(1070×6²) = 38k операций**

### Фаза 2: Торговля (быстро, каждые 5 минут)
**Текущая реальная цена**: S_real=43 500 USD → S*=43 500/43 000=1.012

**LSM (медленный)**:
```
Для Δ на шаге i=25:
1. Пересчитать регрессию на путях НЕ У СТАРОЙ ЦЕНЫ:
   X_new[j] = basis(S*[j,25]) для оставшихся путей после exercise
2. w_new = OLS(X_new → V_cont_new)  ← ЗАНОВО 38k операций!
3. Δ* = w_new · ∂L/∂S |_{S*=1.012}
```

**RLSM (быстрый)**:
```
1. r_t = tanh(Win·[1.012, τ=5/30] + W_res·r_{t-1})  ← 200 операций
2. V_cont* = w_out · r_t  
3. Δ* = w_out · ∂r_t/∂S*  ← всего 400 операций!
```

## Почему полиномы не "за 1 проход"

**Полиномы быстрые для 1 точки**, но LSM требует **переобучения весов** при каждой новой рыночной ситуации:

```
День 25, 10:00: S*=1.012 → fit1 → w₁
День 25, 10:05: S*=1.015 → некоторые пути exercised → 
                    новые X[j] → fit2 → w₂ ← ЗАНОВО!
```

**RLSM reservoir**: фиксированные веса W_res выучены раз и навсегда. Меняются только w_out (10 чисел), обновление рекуррентное:

```
w_out_new = w_out_old + μ·error·r_t  ← 10 умножений!
```

## Визуализация разницы

```
Реальная торговля (500 ребалансировок за день):
LSM: 500 × 38k = 19M операций → 0.2 сек задержка → slippage $50
RLSM: 500 × 400 = 200k операций → 2ms → slippage $2
```

**Для BTC при σ=70%**: цена за 2ms уходит на 0.2%, это $87 на 1 BTC контракте.

## Простая аналогия
```
LSM = каждый раз заново решать систему уравнений 1070×6
RLSM = таблица "S* → Δ*" выучена заранее, lookup за O(1)
```

**В Exp4 RLSM выиграл по CVaR₉₅ на 15%**, потому что ловил микродвижения BTC без задержек, а LSM "зависал" на рефите при vol spikes.
