## 3. Анализ и объяснение результатов

### 3.1 Почему LSM иногда показывает лучший CVaR при высоком d на BTC?

**Этот вопрос — ключевой для понимания результатов.**

Четыре фактора:

1. **Payoff dimension mismatch**: На BTC payoff = max(K-S,0) зависит ТОЛЬКО от цены (dim 0). Дополнительные фичи — «подсказки» для модели, а не аргументы payoff. LSM OLS автоматически присваивает ~0 весов нерелевантным фичам, тогда как RLSM random reservoir MIX all dims equally.

2. **Price overestimation effect**: LSM при d=30 оценивает V₀=7.68 (больше «запас прочности» для хеджа), NLSM даёт V₀=3.22 → начинает хедж с недостаточным капиталом.

3. **FD delta smoothness**: Конечно-разностная дельта LSM — градиент гладкого полинома → стабильный хедж. RLSM autograd через tanh может давать «дёрганую» дельту.

4. **В синтетике (MaxCall, d=100) — LSM однозначно ПРОИГРЫВАЕТ**: CVaR₉₅(LSM)=40.65 vs CVaR₉₅(RLSM)=32.32. Когда ВСЕ измерения влияют на payoff, полиномиальные базисные функции не справляются.

**Практический вывод**: для BTC с 1D payoff и d>5 features — LSM и RLSM СОПОСТАВИМЫ по качеству хеджа. Но RLSM даёт дельту в 86x быстрее при d=30 — это решающее преимущество для автоматизированных систем.

### 3.2 Volatility Risk Premium

Все модели систематически недооценивают рыночные цены опционов потому что:
- Рынок ценит по implied volatility (IV ≈ 67-74% для BTC в марте 2024)
- Модели обучены на realized volatility (RV ≈ 51%)
- IV/RV ratio ≈ 1.3-1.44 — стандартная премия за риск

Это НЕ недостаток моделей. Это фундаментальный экономический феномен: продавцы опционов требуют компенсацию за «jump risk» и «variance risk». Модели правильно оценивают «fair value» при P-мере (историческое распределение).

### 3.3 Время обучения

| d | LSM fit | RLSM fit | Ratio |
|---|---------|----------|-------|
| 1 | 0.10s | 3.87s | LSM быстрее |
| 30 | 108.18s | 3.25s | RLSM в 33x быстрее |
| 100 | 741.92s | 5.75s | RLSM в 129x быстрее |

LSM training: O(n × d²) для OLS с d²/2 полиномиальных фичей.
RLSM training: O(n × h) — линейная по размеру reservoir, не зависит от d.

## 6. Ограничения работы

1. **Ликвидность**: BTC — один из самых ликвидных крипто-активов. Для менее ликвидных активов bid-ask spread шире → модельные цены менее информативны.

2. **American vs European**: реальные биткоин-опционы на Deribit — европейские. Наши модели цены несколько завышены (American ≥ European). Разница мала для OTM краткосрочных опционов.

3. **Jump risk**: модели на historical paths НЕ учитывают «чёрных лебедей» (flash crashes, Luna collapse). Market IV это учитывает.

4. **Transaction costs**: хедж-анализ не включает bid-ask spread и комиссии при ребалансировке. В реальности CVaR₉₅ будет выше.

5. **Training data scarcity**: 3-летняя история BTC (2021-2024) покрывает bull/bear/flat, но не extreme tail events (2008-type crisis).
